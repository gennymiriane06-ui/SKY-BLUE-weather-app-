# ⛅ Sky Blue

Sky Blue is a simple and responsive weather forecast application built using **HTML, CSS, and JavaScript**.  
It allows users to search for any city and view real-time weather information using a public weather API.

<!-- ![Weather App Screenshot](assets/) -->


## ✨Features

* Search by City
 - Enter a city name to get weather details
 - Fetches real-time data using a weather API
 - Displays:
   - City name
   - Temperature (°C)
   - Weather description
   - Weather icon

* 🌡️Weather Information
  - Temperature in Celsius
  - Weather condition description
  - Humidity percentage
  - Wind speed

* 💾Local Storage Support
  - Saves the last searched city
  - Automatically loads it when the page is refreshed

* 🔄Error Handling
  - Shows friendly messages for invalid cities
  - Handles API or network errors

* 📱Responsive Design
  - Works on mobile, tablet, and desktop devices

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Weather data from OpenWeatherMap API
